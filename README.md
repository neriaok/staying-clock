# Staying Clock

שומר מסך-שעון בעיצוב חשוך: מניחים את הטלפון, והמסך נשאר דלוק ומציג שעה ותאריך ברצף — בלי צורך להדליק את הטלפון כדי לדעת מה השעה.

## תכונות

- **מסך דלוק ברצף** דרך [Screen Wake Lock API](https://developer.mozilla.org/en-US/docs/Web/API/Screen_Wake_Lock_API), כל עוד האפליקציה פתוחה.
- **עיצוב חשוך וחסכוני בסוללה**: רקע שחור מלא (חוסך חשמל במסכי OLED), טקסט בעוצמה נמוכה, ללא אנימציות מיותרות.
- **הגנה מפני צריבת מסך (burn-in)**: הטקסט "נודד" בעדינות כל דקה במרחק קטן, שימושי כשהמסך דולק לאורך שעות רבות ברציפות.
- **הגדרות אישיות**: פורמט 12/24 שעות, הצגת/הסתרת שניות, עוצמת בהירות — נשמרות במכשיר.
- **PWA**: ניתן להתקין למסך הבית ולהשתמש כאפליקציה במסך מלא, כולל תמיכה אופליין.

## איך מפעילים

1. פותחים את הקישור בדפדפן הטלפון (Chrome באנדרואיד או Safari באייפון).
2. מוסיפים למסך הבית ("הוסף למסך הבית" / "Add to Home Screen") כדי לקבל חוויית מסך מלא ללא סרגלי דפדפן.
3. פותחים את האפליקציה, מניחים את הטלפון במקום מרכזי — המסך יישאר דלוק אוטומטית.
4. הקשה על המסך פותחת הגדרות (כולל אפשרות לכבות את נעילת המסך).

## הרצה מקומית לפיתוח

```bash
node scripts/dev-server.js 8000
# ואז לפתוח http://localhost:8000
```

Wake Lock דורש הרשה HTTPS או localhost — עבודה מקומית תפעל, ופריסה בפועל (למשל GitHub Pages) מספקת HTTPS אוטומטית.

## תמיכת דפדפנים ב-Wake Lock

נתמך ב-Chrome/Edge לאנדרואיד ו-Safari מגרסה 16.4 ומעלה באייפון. בדפדפן שלא תומך, האפליקציה מציגה הודעה ומבקשת להגדיר "שינה" ארוכה בהגדרות התצוגה של הטלפון כפתרון חלופי.

## מבנה הפרויקט

```
index.html          מבנה הדף והממשק
style.css            עיצוב חשוך, חסכוני בסוללה
app.js                לוגיקת השעון, Wake Lock, הגדרות ואנטי-צריבה
manifest.json         מניפסט PWA (התקנה למסך הבית)
service-worker.js     תמיכה אופליין
icons/                אייקוני האפליקציה
scripts/gen-icons.js   סקריפט חד-פעמי ליצירת האייקונים
scripts/dev-server.js  שרת מקומי פשוט להרצה בזמן פיתוח
```
